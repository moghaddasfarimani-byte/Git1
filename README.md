# kfzocar.ir — سایت معرفی سامانه‌ی مدیریت اجاره خودرو

صفحه‌ی معرفی (Landing) فارسی و راست‌چین برای **kfzocar**، سامانه‌ی مدیریت اجاره خودرو ویژه‌ی رنت‌کاران کیش.
محتوا و طراحی بر اساس بروشور رسمی kfzocar است. دکمه‌های ورود به [app.kfzocar.ir](https://app.kfzocar.ir) لینک شده‌اند.

## بخش‌ها

- هیرو با موکاپ موبایل صفحه‌ی رزرو (لیست متحرک خودروها و اعلان سفارش جدید)
- نوار خودروهای رایج رنت کیش با عکس واقعی
- چرا kfzocar (دغدغه ← راه‌حل)
- ناوگان و قرارداد
- مالی و حسابداری (با نمونه‌ی متحرک تسویه‌ی قرارداد)
- رزرو آنلاین با QR و نمایش زنده‌ی صفحه‌ی رزرو به ۱۴ زبان
- امنیت و آرامش خیال
- QR کد kfzocar.ir

## اجرا

HTML/CSS/JS خالص، بدون build:

```bash
python3 -m http.server 8000
# http://localhost:8000
```

عکس خودروها: `assets/cars/README.md`
