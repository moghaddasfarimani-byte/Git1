# kfzocar.ir — سایت معرفی سامانه‌ی مدیریت اجاره خودرو

صفحه‌ی معرفی (Landing) فارسی و راست‌چین برای **kfzocar**، سامانه‌ی مدیریت اجاره خودرو ویژه‌ی رنت‌کاران کیش.
محتوا و طراحی بر اساس بروشور رسمی kfzocar است. دکمه‌های ورود به [app.kfzocar.ir](https://app.kfzocar.ir) لینک شده‌اند.

## بخش‌ها

- هیرو با تابلوی زنده‌ی «سفارش‌های آنلاین امروز» به سبک تابلوی فرودگاه
- «یک روز در دفتر رنت کیش»: از ۰۷:۴۵ تا ۰۳:۰۰، با آسمان کیش که با اسکرول از طلوع تا شب عوض می‌شود
- تقویم ناوگان با نمایش جلوگیری از رزرو تداخلی (پلاک‌های کیش)
- نقشه‌ی زنده‌ی موقعیت خودروها روی تصویر نقشه‌ی کیش (`assets/kish-map.jpg`)
- شبیه‌ساز تعاملی تسویه‌ی قرارداد: ودیعه جدا از درآمد
- رزرو آنلاین چندزبانه و QR
- امنیت، و QR کد kfzocar.ir

## اجرا

HTML/CSS/JS خالص، بدون build:

```bash
python3 -m http.server 8000
# http://localhost:8000
```
