# KFZO Car — سایت معرفی سیستم اجاره خودرو

صفحه فرود (Landing) فارسی و راست‌چین برای [kfzocar.ir](https://kfzocar.ir).
همه دکمه‌های رزرو به اپلیکیشن [app.kfzocar.ir](https://app.kfzocar.ir) لینک شده‌اند.

- HTML/CSS/JS خالص، بدون نیاز به build
- انیمیشن‌ها: ورود خودرو و جاده متحرک در هیرو، اسکرول‌ریویل، شمارنده، کارت‌های سه‌بعدی، نوار پیشرفت
- بخش ناوگان با ۱۶ خودروی پرطرفدار رنت و فیلتر دسته‌بندی
- عکس خودروها از Wikimedia Commons (مجوز آزاد، با لینک منبع)؛ برای جایگزینی با عکس‌های خودتان `assets/cars/README.md` را ببینید
- مشخصات فنی (موتور، قدرت، گیربکس، ظرفیت، سوخت) برای نسخه رایج هر مدل در بازار ایران

## اجرا

```bash
python3 -m http.server 8000
# http://localhost:8000
```
