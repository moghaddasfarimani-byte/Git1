# عکس خودروها

عکس‌های فعلی سایت از Wikimedia Commons (مجوز آزاد) بارگذاری می‌شوند و لینک منبع روی هر عکس هست.
اگر عکسی بارگذاری نشود، کارت با رنگ گرادیانی و آیکون خودرو نمایش داده می‌شود.

برای استفاده از عکس‌های واقعی ناوگان خودتان:

1. عکس را در همین پوشه بگذارید (مثلاً `camry.jpg`؛ نسبت ۱۶:۱۰، عرض حدود ۸۰۰ پیکسل).
2. در `assets/main.js` مقدار مربوط در `PHOTOS` را به مسیر فایل تغییر دهید:

```js
camry: "assets/cars/camry.jpg",
```
